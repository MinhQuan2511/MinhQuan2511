### 🚀 Highlighted Engineering Projects

#### 🔷 [Vertex Dynamics – Industrial 3D Vision & Robot Trajectory Platform (Capstone)](https://github.com/MinhQuan2511/RMIT-Software-Capstone)
> *Industry Capstone Project in partnership with **ABB Robotics Vietnam***

An end-to-end digital twin web application transforming raw 3D optical scan descriptors (`Feature.txt`) into validated ABB RAPID programs, slashing engineering setup duration by **>95%** (from 52 minutes down to under 1 minute).

> **Pipeline Architecture:** `[3D Vision Scan]` ➔ `[SHA-256 Storage]` ➔ `[Kinematics / Arc Fitting]` ➔ `[Three.js Viewport]` ➔ `[ABB RAPID]`

* **Interactive 3D WebGL Simulation:** Engineered a browser-based millimeter-scale scene in **Three.js** featuring procedural workpiece reconstruction, dynamic torch attitude updates, bead growth animation, and particle spark telemetry locked to a 10 Hz wall-clock clock.
* **2.5D Isometric SVG Visualizer:** Developed an auto-framing vector projection engine incorporating analytical bounding-box calculation and an iterative label anti-collision relaxation algorithm.
* **Deterministic Backend Architecture:** Architected an immutable Node.js backend leveraging **cryptographic SHA-256 content-addressing** and atomic filesystem writes (`writeFileAtomic`, keyed mutex locking) to eliminate cross-tab race conditions.
* **Sub-Millisecond Kinematics:** Pure algorithmic execution latency benchmarked across 200 iterations at **55.8 µs** for linear paths (`MoveL`) and **150.2 µs** for circular arc fitting (`MoveC`).
* **Industrial Procedural Safety:** Enforced a 13-rule static AST prechecker (`rapidPrecheck.js`), two-stage review gates (Geometry Review ➔ Module Review), and hardcoded hardware export lockouts for demo sample files.
* **Tech Stack:** `Next.js (App Router)` `React` `Three.js (WebGL)` `Tailwind CSS` `Node.js` `Express` `ABB RobotStudio`
